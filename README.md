# ❤️ Heart Disease Prediction Using Machine Learning

## 📌 Overview

An end-to-end Machine Learning project that predicts the likelihood of heart disease using patient health attributes. Developed with Python and Scikit-learn, this project covers data preprocessing, exploratory data analysis (EDA), model training, and performance evaluation.

**Key Result:** Logistic Regression achieved **88.52% accuracy** in the reported experiment, outperforming Decision Tree and Random Forest.

## 🎯 Objectives

- Analyze and preprocess heart disease data.
- Perform exploratory data analysis to identify patterns.
- Train and compare multiple classification algorithms.
- Evaluate model performance using accuracy.
- Identify the best-performing model.

## 🛠️ Technologies Used

- **Python** — Core programming language
- **Pandas** — Data manipulation and analysis
- **NumPy** — Numerical computations
- **Matplotlib** — Data visualization
- **Seaborn** — Statistical visualization
- **Scikit-learn** — Data preprocessing, model training, and evaluation

## 🔄 End-to-End Machine Learning Workflow

1. **Data Collection:** Load the heart disease dataset.
2. **Data Cleaning:** Check missing values, duplicates, and inconsistencies.
3. **Exploratory Data Analysis:** Explore data distributions and feature relationships.
4. **Data Preprocessing:** Encode categorical features and scale numerical features when appropriate.
5. **Train-Test Split:** Separate data into training and testing sets.
6. **Model Training:** Train Logistic Regression, Decision Tree, and Random Forest classifiers.
7. **Model Evaluation:** Evaluate predictions using accuracy and other relevant metrics.
8. **Model Comparison:** Compare model performance and select the best-performing model.

## 🤖 Machine Learning Models

- **Logistic Regression:** Predicts the probability of heart disease.
- **Decision Tree:** Classifies data using feature-based decision rules.
- **Random Forest:** Combines multiple decision trees for classification.

## 📊 Model Performance

| Model | Accuracy |
|---|---:|
| Logistic Regression | **88.52%** |
| Random Forest | 85.25% |
| Decision Tree | 75.41% |

**Best Model:** Logistic Regression achieved 88.52% accuracy in the reported experiment.

*Results may vary depending on data preprocessing, dataset composition, and train-test splitting.*

## 💻 Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/Heart-Disease-Prediction-ML.git
```

### 2. Navigate to the Project Directory

```bash

```

### 3. Install Dependencies

```bash
pip install pandas numpy matplotlib seaborn scikit-learn
```

### 4. Run the Project

Run the Python script or open the Jupyter Notebook included in the repository.

For example:

```bash

```
